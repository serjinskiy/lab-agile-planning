───────────────────────────────────────────────────────────────────────
  🎯 СПОСОБ 1: САМЫЙ ПРОСТОЙ (рекомендуется для новичков)
───────────────────────────────────────────────────────────────────────

1. УПАКУЙТЕ ВСЕ ФАЙЛЫ В ZIP-АРХИВ:
   - Выделите все файлы из папки
   - Правый клик мыши → "Сжать в ZIP" (или "Отправить в → Сжатая ZIP-папка")
   - Назовите архив "qbic-ads-landing.zip"

2. ОБРАТИТЕСЬ В ПОДДЕРЖКУ ХОСТИНГА:
   Напишите в чат поддержки вашего хостинга:

   "Здравствуйте! Я новичок и хочу разместить свой сайт.
   У меня есть готовые файлы в ZIP-архиве. Можете помочь их загрузить?"

   - Отправьте им ZIP-архив
   - Они помогут всё настроить!

3. ГОТОВО! 🎉
   Через несколько минут ваш сайт будет доступен по вашему домену.

ТРЕБОВАНИЯ К ХОСТИНГУ:
✅ PHP 7.4 или выше
✅ Apache или Nginx веб-сервер
✅ Поддержка .htaccess (для Apache)
✅ Возможность записи файлов (для сохранения заявок)

ШАГИ ПО УСТАНОВКЕ:

1. ПОДКЛЮЧИТЕСЬ К ХОСТИНГУ
   Используйте один из способов:
   - Файловый менеджер в панели управления (cPanel, ISPmanager и т.д.)
   - FTP-клиент (FileZilla, WinSCP)
   - SSH (для продвинутых пользователей)

2. НАЙДИТЕ КОРНЕВУЮ ПАПКУ САЙТА
   Обычно это одна из:
   - /public_html/
   - /www/
   - /htdocs/
   - /domains/ваш-домен.com/public_html/

3. ЗАГРУЗИТЕ ВСЕ ФАЙЛЫ
   - Скопируйте ВСЕ файлы из архива в корневую папку
   - Убедитесь, что index.html находится в корне (не в подпапке!)

   Правильная структура:
   public_html/
   ├── index.html
   ├── style.css
   ├── script.js
   ├── handler.php
   ├── robots.txt
   ├── sitemap.xml
   ├── .htaccess
   └── images/ (создайте эту папку)

4. УСТАНОВИТЕ ПРАВА ДОСТУПА
   Для handler.php и папки с сайтом:
   - handler.php: 644
   - leads.csv (создастся автоматически): 644
   - папки: 755

5. СОЗДАЙТЕ ПАПКУ ДЛЯ ИЗОБРАЖЕНИЙ
   - Создайте папку "images" в корне сайта
   - Права доступа: 755

6. ПРОВЕРЬТЕ РАБОТУ САЙТА
   - Откройте ваш-домен.com в браузере
   - Сайт должен загрузиться!

Сейчас на сайте используются временные изображения (placehold.co).
Чтобы заменить их на свои:

1. Подготовьте изображения:
   - Hero изображение: 600x500px (или больше)
   - Скриншоты Google Ads: 600x400px
   - Looker Studio дашборды: 700x500px

2. Загрузите в папку images/

   Стало:
   <img src="images/ваше-изображение.jpg">

───────────────────────────────────────────────────────────────────────
  🌐 НАСТРОЙКА EMAIL УВЕДОМЛЕНИЙ (опционально)
───────────────────────────────────────────────────────────────────────

Чтобы получать уведомления на email при новой заявке:

1. Откройте файл handler.php
2. Найдите строку:
   // Uncomment to enable email notifications
   // mail($to, $subject, $message, $headers);

3. Удалите // в начале последней строки:
   mail($to, $subject, $message, $headers);

4. Измените email на свой (строка 149):
   $to = 'ваш-email@example.com';

5. Сохраните файл

⚠️ ВНИМАНИЕ: Email-функция работает не на всех хостингах!
   Если письма не приходят - используйте CSV файл.

───────────────────────────────────────────────────────────────────────
  ❓ ЧАСТЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ
───────────────────────────────────────────────────────────────────────

ПРОБЛЕМА: Сайт не открывается (белая страница)
РЕШЕНИЕ:
- Проверьте, что index.html в корне сайта
- Очистите кэш браузера (Ctrl+F5)
- Подождите 5-10 минут (DNS обновление)

ПРОБЛЕМА: Форма не отправляется
РЕШЕНИЕ:
- Убедитесь, что хостинг поддерживает PHP
- Проверьте права доступа к handler.php (644)
- Проверьте права на запись в папке сайта (755)

ПРОБЛЕМА: Заявки не сохраняются
РЕШЕНИЕ:
- Проверьте права доступа к папке (должна быть возможность создания файлов)
- Убедитесь, что PHP может записывать файлы
- Проверьте логи ошибок PHP на хостинге

ПРОБЛЕМА: Картинки не загружаются
РЕШЕНИЕ:
- Создайте папку "images" в корне
- Загрузите в неё свои изображения
- Обновите пути в index.html

ПРОБЛЕМА: Стили не применяются
РЕШЕНИЕ:
- Проверьте, что style.css загружен на хостинг
- Очистите кэш браузера (Ctrl+Shift+Delete)
- Проверьте путь к файлу в index.html
